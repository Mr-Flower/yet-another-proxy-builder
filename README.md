## ✨ Highlights

- 🔎 **Find any card** — full Scryfall query syntax + a visual advanced‑search builder, plus community high‑DPI art from **MPCFill**.
- 🎨 **Choose the exact printing** — browse every Scryfall printing and MPCFill source in a thumbnail gallery with a large live preview, and filter by source (Scryfall / MPCFill / a single artist source).
- 📋 **Import whole decks** — paste a **Moxfield** or **Archidekt** URL, an **MPCFill `cards.xml`**, or just a plain text decklist (`4 Lightning Bolt`).
- 🖼️ **WYSIWYG canvas** — the multi‑page editor shows cards exactly as they'll print, **including real bleed**, so there are no surprises in the PDF.
- ✂️ **Print‑ready output** — true edge bleed (corners squared off so scans never leave white slivers), cut guides, fully configurable card outlines, duplex layout, and **Silhouette Cameo** registration marks + SVG cut lines.
- 🌑 **Image tuning** — per‑card or bulk brightness / contrast / saturation and a black‑point "darken" pass to clean up dark scans.
- 📚 **Persistent art libraries** — save front/back art once and reuse it instantly; export/import as ZIP, relocate, and auto‑thumbnail.
- 🪪 **Per‑copy editing** — split one copy off a stack ("✂ Scollega copia") to give a single card its own art or text.
- 🧩 **Card Editor** — a layered editor for custom cards (image + text layers, fonts, colours, positioning).
- 💾 **Portable projects & tabs** — work on several decks at once in tabs; each project is a single self‑contained file with 50‑level undo.

## 🎴 Features

### Card Search & Import
- **Scryfall** — search by name, type, colour, mana cost, set, rarity, artist, format legality and more with full query syntax.
- **Advanced search builder** — dropdowns for every filter (colours, CMC, rarity, P/T, format, set, artist, keywords, card properties).
- **MPCFill** — community high‑DPI proxy art with source management, favourites, and DPI/language/content filtering.
- **Moxfield / Archidekt import** — paste a deck URL; the source is auto‑detected and all artwork is fetched.
- **Paste a text decklist** — drop in lines like `2 Sol Ring` or `1x Counterspell`; section headers (`Deck`, `Sideboard`, …) are ignored automatically.
- **Game selector (Magic / Yu‑Gi‑Oh!)** — the *Add Cards* tab has a game dropdown: Magic resolves pasted names via Scryfall, **Yu‑Gi‑Oh!** resolves them via the **YGOPRODeck** API (e.g. `3 Dark Magician`), downloading the card art automatically. The art selector shows every **alternate YGOPRODeck artwork** for a Yu‑Gi‑Oh! card, and new Yu‑Gi‑Oh! cards get a generated default card back (overridable). (Deck‑URL and MPCFill imports remain Magic‑only.)
- **MPCFill `cards.xml` import** and **local image files** (multi‑select), with optional duplicate‑skipping (basic lands merge by quantity).

### Visual Page Editor
- **Multi‑page, zoomable canvas** with all pages stacked vertically.
- **WYSIWYG bleed** — cards render with the same bleed‑extended image the PDF uses, so the preview matches the print.
- **Real card thumbnails** everywhere — search results, previews and the Card panel show the actual art.
- **Drag & drop** reordering, **multi‑select** (Ctrl/Shift‑click across pages), and a rich **right‑click menu** (duplicate, delete, flip, match back, select front/back art, create token).
- **Flip preview** of back art (single / selected / all), **zoom** (15–300 %, Ctrl+Wheel, Fit, 1:1) and **pan** (middle‑drag).
- **Per‑copy editing** — "✂ Scollega copia" splits one copy off a stack so you can give it different art or overlay text.
- **Overlay text** (e.g. `TOKEN`) rendered on the front face in both preview and PDF.

### Art Selection & Libraries
- **Art selector** — every Scryfall printing + MPCFill community art in a big thumbnail gallery with a wide live preview (dimensions, estimated DPI, file size, source).
- **Source filter** — show only Scryfall, only MPCFill, a single MPCFill source, or everything.
- **Scryfall printing cache** — a card's printings are cached locally, so reopening the selector is instant and doesn't re‑query the network.
- **Persistent front & back libraries** — save art once and reuse it (local‑first, no re‑download); search, filter by source, multi‑select batch delete, **export/import as ZIP**, **relocate**, and auto‑thumbnailing.
- **Back art** — pick from Scryfall originals, the library, MPCFill card backs (bulk download ~460), or local files; set a **default** applied to new cards.
- **MPCFill Source Manager** — browse 270+ sources, favourite with a click, restrict searches to favourites.

### Image Adjustment
- **Darken / black‑point** pass to push dark‑grey scan borders to true black.
- **Brightness / contrast / saturation** sliders, applied **per card** or in **bulk** (all / Scryfall‑only / MPCFill‑only), with save‑as‑default and auto‑apply to new Scryfall cards.

### Print & PDF
- **25+ card‑size presets** (plus custom mm dimensions) and **page presets** (A4, A3, Letter, Legal, Tabloid + landscape).
- **True bleed** — edge pixels are *extended* (not stretched‑resized), and **rounded scan corners are squared off** to the border colour so no white slivers survive the cut.
- **Cut guides** drawn *behind* the art (won't bleed through light cards).
- **Card outline guides** — colour, alignment (center/inside/outside), corner radius, full vs corner‑marks, solid/dashed, corner length, line weight.
- **Silhouette Cameo** — Type‑1 registration marks (front pages only, to save ink) + matching **SVG cut lines** exported alongside the PDF; bleed/guides/outlines auto‑suppressed in this mode.
- **Print modes** — Duplex (mirrored back columns), Fronts Only, Backs Only — with **auto‑centering** and optional manual grid override.
- **Card position adjustment** — nudge the whole grid by an exact horizontal/vertical offset in mm (decimals welcome, e.g. `0,45`) to compensate for a printer that prints slightly off‑centre. Bleed width and offsets are precise numeric fields where `.` and `,` are interchangeable decimal separators.

### Card Editor
- A **layered editor** for custom cards: image and text layers with font, size, colour, opacity, rotation, stroke and positioning; live canvas preview with drag‑to‑move and selection handles; export to PNG/JPEG.

### Projects & UX
- **Multi‑project tabs**, each with independent state, **50‑level undo/redo**, and a self‑contained portable project file.
- **Sort & filter** by name, type, rarity, colour, CMC, set, artist… with a compact filter bar above the grid.
- **Fluent dark theme** with an ultra‑violet accent, busy/loading overlays with step‑by‑step progress, async background image loading, and an automatic **update check** against GitHub releases.

## 📖 Usage Guide

### Getting started
1. Launch the app — you'll get a welcome screen.
2. **New Project** / **Open Project** (Ctrl+N / Ctrl+O).
3. Add cards (below), tune the **Layout** tab, and **Export PDF**.
4. Open more projects in new tabs — each is independent.

### Adding cards
- **Scryfall:** type a name (or use Advanced Search), then double‑click a result to add it.
- **MPCFill:** switch the source, search, and pick high‑DPI community art; manage/favourite sources.
- **Decklist URL:** paste a Moxfield/Archidekt link in *Import Deck*.
- **Text list:** paste lines like `4 Lightning Bolt` into *Paste Card List* → *Add Cards from List*.
- **Files:** *+ File* in the toolbar (multi‑select).

### Choosing art
- Double‑click a card on the canvas (or use the Card panel buttons) to open the **art selector**.
- Library matches show first (instant), then Scryfall printings + MPCFill art.
- Use the **source filter** to narrow to Scryfall, MPCFill, or one source; expand **MPCFill Filters** to tune DPI/language/types.
- Right‑click any MPCFill tile to **Save to Library**; tick **Apply to all** to update every copy.
- Need just one copy different? Select the card and click **✂ Scollega copia**, then change its art/text.

### Layout & print (Layout tab)
- **Page size & print mode** (Duplex / Fronts / Backs).
- **Cut guides** and fully configurable **card outlines** (colour picker, alignment, radius, full/corners, solid/dashed, weight).
- **Silhouette Cameo** — enable registration marks and/or SVG cut‑line export.
- **Card size** preset or custom mm; **bleed width** (mm) and **card position adjustment** (horizontal/vertical offset in mm, decimals allowed) to re‑centre the print on a misaligned printer.
- **Grid** auto‑fit or manual; **storage** cache size + clear.

### Export, save, undo
- **Export PDF** — bleed‑extended art, cut guides behind the art, outlines on top, mirrored duplex backs, optional Cameo marks + SVG.
- **Save / Open** — portable project files bundling all artwork; share a single file between machines.
- **Ctrl+Z / Ctrl+Y** — 50‑level undo across every card operation.

## 📂 File Locations

Data lives under the per‑user app‑data folder — `%AppData%\MTGProxyBuilder\` on Windows, `~/.config/MTGProxyBuilder/` on Linux:

| Item | Path | Notes |
|------|------|-------|
| App settings | `app_settings.json` | Defaults, MPCFill filters, update toggle |
| Image cache | `ImageCache/` | Downloaded card images (+ Scryfall printing lists) |
| Bleed cache | `BleedCache/` | Bleed‑processed images (regenerated when the algorithm changes) |
| Extracted projects | `ExtractedProjects/` | Temp images from opened projects (cleared on startup) |
| Front/Back libraries | `FrontArtLibrary/` · `BackArtLibrary/` | Saved art + `catalog.json` + `Thumbnails/` |
| Projects | Anywhere you choose | `.mtgproj` ZIP archives |

## 🩹 Troubleshooting

- **Scryfall errors** — check your connection; the app respects Scryfall's ~10 req/s limit automatically.
- **No MPCFill results** — you must be online for the first source fetch; turn off *Favs only*, try non‑fuzzy matching, and check Settings → MPCFill filters; in the art selector, *Clear Filters* then *Re‑search*.
- **Moxfield 403** — Moxfield uses Cloudflare; the app uses `curl` to get through. Private decks can't be imported.
- **Slow PDF / first preview** — bleed processing converts each unique image once, then caches it (and shares that cache with the canvas preview). Big decks take a few seconds; the spinner shows progress.
- **Disk usage** — Layout tab → *Clear Cache*. Bleed/extracted caches auto‑clean on startup; image cache on exit.
